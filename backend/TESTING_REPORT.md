# Automated MCQ Exam Portal — Testing & Quality Assurance Report

## Scope
Backend testing for authentication, validation, RBAC, question/exam business rules, automatic evaluation, and controller-to-service integration.

## Existing baseline on main
The repository already contains Jest unit tests for:
- AuthService
- EvaluationService
- ExamsService
- QuestionsService

## Added test coverage
- Auth DTO equivalence/boundary tests
- Role guard positive/negative security tests
- Exam passing-mark, duration, and question-pool boundaries
- Automatic evaluation pass/fail and grade boundaries
- Controller -> service integration for exam creation
- Controller -> CoursesService -> ExamsService integration for available exams

## Test techniques
1. Equivalence partitioning
2. Boundary value analysis
3. Negative/security testing
4. Arrange-Act-Assert

## Required commands
Run from backend/:

npm ci
npx prisma generate
npm test -- --runInBand
npm run test:coverage -- --runInBand

## CI
The supplied GitHub Actions workflow runs Jest with coverage on Node 20 and uploads the coverage folder as an artifact.

## Important evidence rule
Do not invent pass/fail counts or coverage percentages. Use the Jest console output and coverage report generated by the local run or GitHub Actions run.
